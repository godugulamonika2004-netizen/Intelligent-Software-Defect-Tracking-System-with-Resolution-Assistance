# 🐞 Intelligent Software Defect Tracking System with Resolution Assistance

## Project Overview

An interactive Streamlit dashboard developed using Python, Pandas, and Plotly to analyze software bug records.

## Features

- Bug Status Analysis
- Priority Analysis
- Severity Analysis
- Sprint-wise Bug Distribution
- Module-wise Bug Distribution
- Root Cause Analysis
- Resolution Analysis
- Team Performance
- Engineer-wise Bug Distribution
- Bug Resolution Trends
- Resolution Time Analysis
- Search and Filtering
- Download Filtered Bug Report

## Technologies Used

- Python
- Streamlit
- Pandas
- Plotly

## Dataset

The dashboard analyzes bug records containing information such as:

- Bug ID
- Sprint
- Release Version
- Module
- Feature
- Component
- Priority
- Severity
- Status
- Resolution
- Root Cause
- Date Reported
- Date Closed
- Resolution Time
- Team
- Assigned To

```bash
pip install -r requirements.txt
